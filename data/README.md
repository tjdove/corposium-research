# data/

Raw datasets behind `docs/calibration/SOURCES.md` (Story 2.3). Every file here is
regenerated by one stdlib-only script, with no API keys:

```bash
python data/fetch.py        # from the repo root; overwrites the three CSVs below
```

All files retrieved **2026-10-04**. Timestamps are UTC. Files are CSV and under 1 MB each.
A re-fetch should reproduce the checksums below unless the upstream source revises
history. If it does, commit the new file and note it here.

---

## `usdcusd_1h_calm_2023-02-27_2023-03-03.csv`

- **What:** USDC/USD hourly OHLCV on Bitstamp, the calm week before the SVB failure.
- **Source:** Bitstamp public REST API (no key):
  `https://www.bitstamp.net/api/v2/ohlc/usdcusd/?step=3600&limit=1000&start=1677456000&end=1677888000`
  (2023-02-27T00:00Z to 2023-03-04T00:00Z, end exclusive).
- **Rows:** 120 (Mon 27 Feb 00:00 → Fri 3 Mar 23:00).
- **Columns:** `timestamp_utc, unix, open, high, low, close, volume` (volume in USDC).
- **sha256:** `e91187416173753c14ad563e0942989307fe8c83ef02ba2611190f713e033bcf`
- **Caveat:** Bitstamp's USDC/USD book is thin. 13 of 120 hours have zero volume (close
  carried forward), and single prints move the close (low 0.99636). Realised volatility from
  this file is an *upper* estimate for a calm week.

## `usdc_supply_defillama_2023-03-01_2023-03-20.csv`

- **What:** total USDC circulating supply across all chains, one value per UTC day.
- **Source:** DefiLlama stablecoins API (no key), USDC is stablecoin id 2:
  `https://stablecoins.llama.fi/stablecoincharts/all?stablecoin=2`, filtered to
  2023-03-01 … 2023-03-20 inclusive (field `totalCirculating.peggedUSD`).
- **Rows:** 20.
- **Columns:** `date_utc, unix, total_circulating_pegged_usd`.
- **sha256:** `969ed59eac1d2deb63e89587a5a540fd2f91e94d00c4af1e07eefc23a5f421ca`
- **Notes:** DefiLlama aggregates on-chain supply across chains. It's a secondary source
  for Circle's net redemptions (primary: Circle's transparency reports / on-chain
  `totalSupply` per chain, which need an archive node or Circle's monthly attestations).

## Not used, and why

- **CoinGecko** `/coins/usd-coin/market_chart/range`: the public API only returns the last
  365 days (`error_code 10012` on 2026-10-04); 2023 data needs a paid key.
- **Coinbase Exchange**: no USDC-USD order book (USDC converts 1:1 on Coinbase), so no
  candles.
- **Kraken** `OHLC`: returns only the most recent 720 candles.
