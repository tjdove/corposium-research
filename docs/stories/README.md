# Stories

One file per story, named `N-M-slug.md` (epic N, story M), with an optional
`N-M-slug.context.xml` generated by the dev manager and an optional
`N-M-slug.learnings.md` written after review when a story taught something.

Status lives on line 3: `drafted | ready-for-dev | in-progress | review | done | blocked`.

Template:

```markdown
# Story N.M: Title

Status: drafted

## Story
As a ..., I want ..., so that ...

## Acceptance Criteria
1. ...

## Tasks / Subtasks
- [ ] Task (AC: n)
  - [ ] Subtask

## Dev Notes
### Architecture Alignment
### Learnings from Previous Story
### Project Structure Notes
### Implementation Approach
### References

## Dev Agent Record
### Context Reference
### Agent Model Used
### Debug Log References
### Completion Notes List
### File List

## Change Log
```

Senior review is appended by the dev manager as `## Senior Developer Review (AI)` with
the AC-evidence table, task verification table, findings and action items.
